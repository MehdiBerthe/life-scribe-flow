# Agent Instructions

- Prefer TypeScript and modern ES modules when adding or updating code in this repository.
- Run `npx tsc --noEmit`, `npx tsc --noEmit -p components-app/tsconfig.json`, and `npx vitest run` before completing any task that changes code.
- Keep documentation concise and task-focused; update existing docs rather than adding duplicates.
- When editing React components under `components-app/`, ensure routes continue to read the `?user=` query parameter.
